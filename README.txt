STUDENT PERFORMANCE PREDICTOR — QUICK START

Requirements:
- Python 3
- pandas
- scikit-learn
- streamlit

Open Command Prompt in this folder and run:
1. python -m pip install pandas scikit-learn streamlit
2. python generate_dataset.py
3. python train_model.py
4. python -m streamlit run app.py

Then open the Local URL shown in Command Prompt (usually http://localhost:8501).

Files:
- generate_dataset.py: creates a synthetic demonstration dataset
- student_data.csv: dataset (generated by step 2)
- train_model.py: trains and saves the Decision Tree model
- student_model.pkl: trained model (generated by step 3)
- app.py: Streamlit user interface
- Mini_Project_Report.docx: project report

Important limitation:
The dataset is synthetic and labels are generated using simple rules. The reported accuracy measures performance on this demo dataset only. It should not be interpreted as evidence of real-world prediction accuracy.
